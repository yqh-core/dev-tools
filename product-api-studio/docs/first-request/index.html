GUIDE 01 · REQUEST BASICS

Send your first request

Start with a URL, choose a method, then inspect what the server returns.

  1. Create a request

    Open the workspace and select Create your first request. For later requests, use + Request in the collection toolbar. Give each request a name you will recognize later.

  2. Enter the endpoint

    Choose an HTTP method and enter a complete URL, for example https://httpbin.org/get. Use Query Params to add or edit URL parameters without hand-editing the query string.

  3. Add headers or a body when needed

    Add request headers by name and value. For methods that send content, enter a raw request body. Only add credentials when you trust the destination.

  4. Send and inspect

    Select Send. Read the response status and elapsed time first, then expand response headers or inspect the formatted body. A transport error and an HTTP error status are different things: an HTTP 404 is still a response from the server.

Requests pass through the first-party API relay. The relay applies destination and size limits; it is not a direct browser-to-server connection.

Fix request or authentication errors such as 400 or 401 before sending again. For a relay connection failure or a temporary HTTP 408, 425, 429 or 5xx response, select Retry request beside the error or response status. Retry is manual; check for side effects before repeating a request that changes server data.
