GUIDE 04 · DATA & PRIVACY

Know where your API data goes

A clear boundary matters more than a broad “private” promise.

Saved workspace data

Collections, request settings, scripts and environment values are stored in this browser's site storage for the current website origin. Browser storage is not encrypted by API Studio. Anyone with access to the same browser profile may be able to inspect it.

When you send or run requests

The request URL, headers and body pass through the first-party API relay. The relay validates destinations and applies request, response and timeout limits. Do not send credentials to an endpoint unless you trust that endpoint and understand its policy.

Secret fields

Marking a variable as secret masks its value in the interface and enables redaction in supported exports and reports. It does not encrypt the value in browser storage, and automatic detection cannot identify every credential embedded in free-form scripts, query strings or request bodies.

Backups and imports

Postman v2.1 export is an interchange format, not a complete API Studio backup. API Studio includes a versioned, browser-generated backup and restore tool. The default export excludes marked secret values and removes common credential headers and URL credentials where they are recognized. It may not detect unmarked credentials in free-form text, scripts, query strings or request bodies. Exporting marked secrets requires a separate confirmation. Restore validates the archive and previews its contents and conflicts before you choose Replace or Merge. You download and import the archive yourself; it is not automatically uploaded to the relay. Review backups before sharing them, and store any archive containing credentials securely.

Do not use a shared or untrusted browser profile for production secrets. Remove sensitive values before sharing a collection file.
